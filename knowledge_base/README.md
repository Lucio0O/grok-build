# Grok Build 产品知识库

本知识库面向**产品经理、设计、运营、解决方案、企业客户成功**等非工程背景读者，系统说明 Grok Build（命令行产品名 `grok`）是什么、怎么运转、各模块如何协作、以及产品决策时需要理解的边界。

它不是用户手册的复制，也不是源码注释。写法是：**先讲原理和思路，再讲流程和方法，最后才点到必要的实现位置**。技术细节会刻意省略。

仓库里另有面向使用者的操作指南：`crates/codegen/xai-grok-pager/docs/user-guide/`。需要「怎么点、怎么配」时请读用户指南；需要「为什么这样设计、模块之间怎么配合」时读本知识库。

## 阅读约定

- **用户**指坐在终端前的开发者或自动化脚本的调用方。
- **Agent / 智能体**指当前这次会话里「会思考、会调工具、会改代码」的那一侧，不是某一个模型品牌名。
- **模型**指真正生成文字和工具调用的大模型（默认是 SpaceXAI 的编码模型）。
- **工具**指模型可以向宿主申请执行的动作，例如读文件、改文件、跑命令、搜网页。
- **宿主**指本仓库实现的运行时：它接用户输入、组提示、调模型、执行工具、把结果画回界面。
- 文中的路径如 `~/.grok/` 表示用户机器上的 Grok 家目录；可用环境变量 `GROK_HOME` 改掉。
