# 14 界面与交互

驾驶舱是全屏终端界面。它不执行工具，只让人**看见 Agent 在干什么，并在该出手时出手**。本章讲屏幕怎么分、信息怎么呈现、有哪些旁路入口。完整快捷键表见用户指南。

---

## 三种屏幕

| 屏幕 | 干什么 |
|---|---|
| 欢迎 | 登录、挑最近会话、看到从其它助手导入的会话线索 |
| 对话 | 回滚区 + 底部输入，主战场 |
| 总览（Dashboard） | 所有顶层会话一行一个：偷看、打开、派活、停掉 |

极简模式是对话屏的另一种画法：已完成的块进入**终端自己的回滚历史**，底部只留正在发生的事和输入框。主题在极简模式下不生效，跟终端 16 色走。`/minimal` 与全屏切换会重启到同一会话，把选择记住。

嵌入 Neovim / Vim / Emacs 的终端时，界面会收起一些会乱码的高级终端序列。这是兼容，不是功能残缺。

---

## 对话屏：两块加一层

### 回滚区

按时间堆：

- 用户提示（常吸顶，方便知道「正在回哪一句」）
- 模型回复：流式 Markdown、代码高亮、表格、任务列表
- 思考：可折叠，可在设置里不显示
- 工具：命令、差异、搜索结果；连续的只读动作可以折成一行
- 待办条

选中一条可以折叠、复制正文或元数据（例如当时跑的命令）、全屏打开。发送新提示时，默认把刚发送的那句顶到视口上方，让回复从「新一页」开始——可关。

### 输入框

多行编辑、撤销、芯片（附件等）。普通模式像常见命令行；可改成 Vim 编输入。回滚区的 Vim 导航是另一开关，不要和输入 Vim 绑死。

输入框之上可以出现：斜杠模糊菜单、`@` 文件挑选、队列中的待发提示。一轮进行中仍能打字，那是排队，不是改正在跑的那一轮（改历史提示的入口目前关掉了，因为滚动体验不好）。

### 弹层

命令面板、参数二选、会话选择、文档选择、设置、扩展五页签、许可、计划预览……弹层打开时，对不上号的按键被吃掉，避免「在菜单里误发一条提示」。

---

## 人如何打断和批准

- 取消当前轮、清空草稿、打开回退，共用 `Esc` / `Ctrl+C` 的状态机，见 [03](03-用户如何使用.md)
- 许可可以弹层，也可以在总览偷看里用数字键快选
- 计划预览支持滚动、行评、打回、批准
- `Ctrl+B` 把当前命令降到后台
- 任务面板看孩子和挂着的活

这些是「人在回路里」的全部主按钮。新功能若需要人点一次，应挂在这几处之一，而不是再发明一种弹窗家族。

## 内容怎么画出来

### 文字

Markdown 按流式来：后面还在涨，前面已经稳定的部分会冻结，避免整页闪。删除线等语法和「模型爱打的单个波浪号」做过和解，避免误伤。

解析规则有一份无界面的核心实现，保证分析和画出来的是同一套语法。产品上可以承诺「你复制出来的结构和它当时看见的一致」。

### 图

Mermaid 默认在终端里画成字符图（流程、时序、状态等子集）。点「打开 / 复制路径」才在子进程里渲染成图片，用系统查看器打开，不在 TUI 里内嵌位图。渲染隔离是为了坏图别把主界面带崩。

### 主题

若干内置主题，可跟随系统深浅，大约定期问一次操作系统。真彩色会按终端能力降到 256 或 16 色。语法高亮有自己的主题文件。极简模式不理这些。

### 剪贴板

本机、终端复用器、远程序列三条路，按环境和信任选择。SSH 场景有实验性包装，让剪贴板仍能回到本地。`/doctor` 用来诊断颜色、剪贴板、复用器、语音。

## 总览屏

一行一个顶层 Agent，按状态排：等人 → 干活 → 空闲 → 别人窗口里未加载的 → 完成 → 失败。空闲只露出最近的若干，其余折进「还有 N 个」。未加载组默认折叠，因为它是背景噪音。

底部派活框和对话输入是同一套皮。派活**总是新开会话**。可以派完就跳进去，也可以只派在总览里盯着。偷看用来扫一眼对话和回答许可，不必完整附着。

搜索过滤行；按工作目录改排序。停会话要确认，避免手滑。

子代理不出现在这里。见 [09](09-子代理与协作.md)。

## 语音

只做听写：麦克风 → 文字进当前输入目标（对话、总览派活、偷看回复）。不直接当命令执行。

可能受账号档位和远程功能开关限制。系统各异：有的平台用子进程采麦，避免音频栈常驻吃内存。没声音先走 `/doctor` 的语音段和系统权限，不要先怀疑模型。

---

## 从其它助手过来

欢迎页在「干净的第一次」会扫其它产品留下的会话，选择器里有单独一列。这是迁移体验，不是默认每次启动的噪音。也可以用专门命令导入。

键盘在 VS Code 家族集成终端里，部分快捷键会和编辑器抢——扩展弹层在那些终端里更推荐用斜杠命令打开。换行快捷键也因终端而异，用户指南有表。`/doctor` 是第一应答。

## 界面架构对产品的含义（只需这几条）

- **动作同步、副作用异步**：按键先改状态，联网和画图在后台完成再回来。所以界面可测，也不会「点一下卡死整屏」。
- **驾驶舱可以重连总台**：断线后把多个 Agent 重新加载，偷看位置尽量恢复。
- **极简靠主程序注册**：少一个安装步骤，极简就不可用。发行物必须带齐。
- **历史行内编辑关掉了**：需求如果是「改上一句重跑」，当前正路是回退再发，不是双击旧气泡。

---

## 读完本章你应该能讲清

- 三屏：欢迎、对话、总览；对话还有全屏/极简两种画法。
- 人的主操作：发送、取消、批准、规划预览、后台、回退。
- 图默认是字符，位图是懒加载的旁路。
- 总览管顶层会话，不管孩子。
